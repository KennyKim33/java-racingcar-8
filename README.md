# 자동차 경주

## 자동차
- [ ] 자동차는 이름을 가진다.
- [ ] 무작위 값(0~9)이 4이상일 경우에만 전진할 수 있다.


## 자동차 경주
- [ ] 시도 횟수만큼 게임을 실행한다.
- [ ] 자동차 게임을 완료한 후 누가 우승했는지 알려준다.
- [ ] 우승자는 여러 명일 수 있다.


## 입력
- [ ] 경주할 자동차 이름을 입력받는다.
- [ ] 시도할 횟수를 숫자로 입력 받는다.


## 출력
- [ ] 차수 별 실행 결과는 자동차 이름과 함께 출력한다.
- [ ] 우승자가 여러 명일 경우에는 쉼표(,)를 이용하여 구분한다.

## 예외 `IllegalArgumentException`
- [ ] 자동차 이름 입력 검증
    - [ ] 자동차의 이름은 5자 이하만 가능하다.
    - [ ] 입력의 마지막은 콤마(,)로 끝날 수 없다.
    - [ ] 자동차의 이름들은 콤마(,)로 구분 해야 한다.
    - [ ] 이름에 빈 값은 입력할 수 없다.
    - [ ] 입력에 공백이 포함될 수 없다.
    - [ ] 자동차 이름은 중복될 수 없다.
- [ ] 시도 횟수 입력 검증
    - [ ] 빈 값은 입력할 수 없다.
    - [ ] 양의 정수만 입력 가능하다.
    - [ ] 음수는 불가능하다.
    - [ ] '0'으로 시작하는 수는 입력할 수 없다.
