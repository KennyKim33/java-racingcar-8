# 자동차 경주

## 자동차
- [ ] 자동차는 이름을 가진다.
- [ ] 자동차는 이동거리를 가진다.
- [ ] 이동 전략에 따라 움직일 수 있다.
- [ ] 자동차 이름 입력 검증
  - [ ] 이름은 `null`이거나 빈칸일 수 없다
  - [ ] 이름은 5자 이하만 가능하다
  - [ ] 이름은 영문, 숫자, 한글만 가능하다 (특수문자 불가)

## 숫자 생성기
- [x] 무작위 값(0~9) 생성

## 전진 규칙
- [x] 생성한 값이 4이상이라면 자동차 전진 명령


## 자동차 경주
- [ ] 시도 횟수만큼 게임을 실행한다.
- [ ] 자동차 게임을 완료한 후 누가 우승했는지 알려준다.
- [ ] 우승자는 여러 명일 수 있다.


## 입력
- [ ] 경주할 자동차 이름을 입력받는다.
  - [ ] 콤마(,) 로 구분하여 입력받는다.
- [ ] 시도할 횟수를 숫자로 입력 받는다.


## 출력
- [ ] 차수 별 실행 결과는 자동차 이름과 함께 출력한다.
- [ ] 우승자가 여러 명일 경우에는 쉼표(,)를 이용하여 구분한다.

## 입력 검증
- [ ] 자동차 이름 입력 검증
  - [ ] 전체 입력이 `null`이거나 빈칸일 수 없다.
  - [ ] 마지막이 콤마(,)로 끝날 수 없다.
  - [ ] trim 후 빈 이름이 있으면 안 된다.
  - [ ] 자동차 이름은 중복될 수 없다.

- [ ] 시도 횟수 입력 검증
  - [ ] `null`이거나 빈 값일 수 없다.
  - [ ] 숫자 형식이어야 한다.
  - [ ] 양의 정수만 가능하다. (1 이상)

## 예외 처리
- [ ] 모든 검증 실패 시 `IllegalArgumentException` 발생
- [ ] 적절한 에러 메시지 포함
