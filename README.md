# 자동차 경주

## 자동차`Car`
- [x] 자동차는 이름을 가진다.
- [x] 자동차는 이동거리를 가진다.
- [x] 이동 전략에 따라 움직일 수 있다.
- [x] 자동차 이름 입력 검증
  - [x] 이름은 5자 이하만 가능하다
  - [x] 이름은 영문, 숫자, 한글만 가능하다 (특수문자 불가)

## 숫자 생성기 `NumberGenerator`
- [x] 무작위 값(0~9) 생성

## 전진 규칙 `MovingStrategy`
- [x] 생성한 값이 4이상이라면 자동차 전진 명령


## 경주 자동차 생성기 `RacingCarFactory`
- [x] 입력받은 자동차 이름으로 경주 자동차 객체 리스트 생성

## 자동차 경주 `RaceService`
- [ ] 모든 자동차의 이동을 시도한다.
- [ ] 현재 자동차 상태를 반환한다.

## 경주 매니저 `RaceManager`
- [ ] 시도 횟수만큼 경주 라운드를 진행한다.
- [ ] 각 라운드 결과를 수집한다.
- [ ] 전체 경주 결과를 반환한다.
- 
## 경주 결과 `RaceResult`
- [ ] 라운드별 결과를 보관한다.
- [ ] 최종 우승자를 판정한다.
  - [ ] 최대 이동 거리를 계산한다.
  - [ ] 최대 거리와 동일한 자동차들을 우승자로 선정한다.


## 입력 `InputView`
- [x] 경주할 자동차 이름을 입력 받는다.
- [x] 시도할 횟수를 숫자로 입력 받는다.


## 출력 `OutputView`
- [ ] 차수 별 실행 결과는 자동차 이름과 함께 출력한다.
- [ ] 우승자가 여러 명일 경우에는 쉼표(,)를 이용하여 구분한다.

## 공통 검증 `StringValidator`
- [x] 입력값은 `null`이거나 빈 칸일 수 없다. 

## 경주 자동차 이름 검증 `CarNamesValidator`
- [x] 자동차 이름 입력 검증
  - [x] 콤마(,)로 시작할 수 없다.
  - [x] 마지막이 콤마(,)로 끝날 수 없다.
  - [x] 자동차 이름은 중복될 수 없다.

## 시도 횟수 검증 `AttemptCountValidator`
- [x] 시도 횟수 입력 검증
  - [x] 숫자 형식이어야 한다.
  - [x] 양의 정수만 가능하다. (1 이상)

## 예외 처리
- [x] 모든 검증 실패 시 `IllegalArgumentException` 발생
- [x] 적절한 에러 메시지 포함
